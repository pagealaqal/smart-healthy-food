# صِحّة — Smart Healthy Food

موقع عربي متكامل من 10 صفحات مترابطة، بتصميم متجاوب واتجاه قراءة من اليمين إلى اليسار. يستخدم HTML5 وملف CSS خارجيًا وJavaScript.

## التشغيل والمعاينة

من مجلد الموقع افتحي الطرفية وشغلي:

```bash
python3 -m http.server 3000
```

ثم افتحي `http://localhost:3000` في المتصفح. لا يحتاج الموقع إلى تثبيت إطار عمل أو قاعدة بيانات. تعمل صور الطعام عبر مسارات الوسائط المدارة الخاصة بمعاينة المشروع؛ للحصول على عرض الصور كما صُمم، افتحي الموقع في معاينة Manus أو أبقي اتصال الإنترنت متاحًا في بيئة المشروع.

## الصفحات

- `index.html` — الرئيسية وروابط الأقسام.
- `about.html` — من نحن والرسالة والأهداف.
- `nutrition.html` — جدول القيم الغذائية والأسعار.
- `register.html` — إنشاء حساب والتحقق من المدخلات.
- `order.html` — تفاصيل التوصيل والتحقق من الكمية والهاتف والبريد وحساب الإجمالي.
- `calculator.html` — حاسبة تفاعلية للأسعار والكميات.
- `bowls.html`, `wraps.html`, `smoothies.html`, `snacks.html` — صفحات فئات الوجبات.

## الملفات المشتركة

`styles.css` هو ملف التنسيق الخارجي، و`app.js` يحتوي منطق النماذج والحاسبة والتنقل. صور الطعام محفوظة محليًا داخل `images/` وتُعرض بعناصر `img`، لذلك تعمل صفحات الموقع مستقلة عن نطاق Manus. `generate_pages.py` يولد صفحات HTML من القوالب والبيانات؛ بعد تعديل القالب أعيدي تشغيل `python3 generate_pages.py`.

## ملاحظات مهمة

تتحقق النماذج من البيانات وتعرض ملخص السعر، لكنها لا ترسل بيانات الحساب أو الطلب إلى خادم ولا تنفذ الدفع. القيم الغذائية تقريبية وقد تختلف بحسب المكونات والكمية وطريقة التحضير. يمكن تعديل بيانات القائمة داخل `generate_pages.py` و`app.js` و`nutrition.html` عند الحاجة.
